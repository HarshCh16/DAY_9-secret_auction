# Blind Auction  

In this type of auction, all bidders simultaneously submit sealed bids so that no bidder knows the bid of any other participant. The highest bidder pays the price that was submitted. The bidders can can only submit one bid each. Furthermore, as bidders cannot see the bids of other participants, they cannot adjust their own bids accordingly.

## How this program runs

This program is beginner-friendly and built using basic Python concepts, making it perfect for learning purposes. It primarily uses:

Dictionaries for storing user names and their corresponding bids.

While loops to continuously gather input until bidding ends.

Conditional statements to control the flow based on user responses.

String formatting for displaying the winner neatly.
